# Place the four new Momentum One videos across the homepage

## Goal
Use each supplied video where its message is most relevant, without turning the page into a wall of moving media or distracting students from the application form.

## Placement
1. **Landscape “Start Uni” film directly below the first screen**
   - Place the 20-second 16:9 film immediately after the hero and application form, before the awarding-university strip.
   - Present it as a wide cinematic transition into the rest of the page, with a short supporting line and a clear “Check my options” action outside the video.
   - Keep it full-width on phones and desktops with a stable 16:9 frame.

2. **Courses loop inside the Courses section**
   - Add the 8.4-second square course animation beside the Courses heading on desktop and above the course deck on phones.
   - Keep the existing interactive course deck and comparison tool as the usable content. The loop acts as an animated introduction, not a replacement.

3. **Campuses loop inside the Campuses section**
   - Place the square UK map loop beside the campus introduction, followed by the existing photo-led campus choices.
   - Preserve each campus action so students can preselect their nearest location in the application.

4. **How It Works loop inside the application journey**
   - Pair the square five-step rocket loop with the journey heading and timeline.
   - On desktop, use a two-column introduction. On phones, show the loop before the timeline so the sequence reads naturally.

5. **Keep the existing portrait promotional film**
   - Retain the current 9:16 film in its existing editorial section because it serves a different role from the new landscape and square animations.
   - Adjust spacing only where needed so the page alternates between information, interaction and motion rather than stacking videos too closely.

## Playback and accessibility
- Upload all four files through the website asset delivery system and create lightweight poster images from representative frames.
- Play silently, inline and on a loop only when each video is near the screen.
- Pause videos when they leave the screen or the browser tab is hidden.
- Show the poster instead of motion for reduced-motion and data-saving visitors.
- Keep all important headings, facts and actions as normal page content rather than relying on words embedded in the films.
- Give every video a fixed aspect ratio to prevent page movement while it loads.

## Visual treatment
- Use one consistent video treatment: restrained border, clean crop, subtle depth and the existing navy, teal and gold palette.
- Avoid oversized decorative cards around the videos.
- Ensure the three square loops remain legible at phone width and do not compete with section controls.

## Validation
- Check all five homepage videos on a 393px phone and a wide desktop.
- Confirm the application remains visible and easy to complete on the first screen.
- Confirm only nearby videos play, all others remain paused, and tab switching pauses playback.
- Confirm reduced-motion visitors see stable poster images.
- Check every section action still scrolls to the application with the correct course or campus selected.
- Confirm the page loads without layout movement, console errors or broken media requests.
